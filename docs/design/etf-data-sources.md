# ETF 工具上游调研（`etf`）

> 回答的问题：**「全市场 ETF 有多少、多大、现在贵不贵（折溢价）、跟踪的是什么指数？」**
> 本文只记录**上游接口的逆向结论**（字段、参数、实测数字、坑）；
> 领域模型与展示方案见 [`etf-tool.md`](./etf-tool.md)。

调研时间：**2026-09-22**（周二，收盘后 / 盘中各测了一轮）。所有数字均为实测，非推测。

---

## 0. 结论摘要

| 需要的信息 | 来源 | 请求数 | 频率 |
|---|---|---|---|
| 场内行情（价格/涨跌/成交额/换手/规模/折溢价/上市日） | `push2.eastmoney.com/api/qt/clist/get`（**接口 A**） | 17（1623 行 ÷ 100/页） | 交易时段每 30 分钟 |
| 跟踪指数 + ETF 分类 + 区间涨跌 + 1 年最大回撤 | `datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_FUND_ETFLIST`（**接口 B**） | 2（1675 行 ÷ 1000/页） | 每日 |
| 单只基金的费率/规模/管理人/成立日（详情抽屉） | `fundmobapi.eastmoney.com/FundMNewApi/FundMNDetailInformation`（**接口 C**） | 1/只（按需 + 落库缓存） | 用户下钻时 |

**没有**任何单一接口同时给出行情与跟踪指数 —— 因此本工具是「接口 A × 接口 B 按代码 join」，
并允许 B 失败时降级（分类回退到名称判定，见设计文档）。

## 1. 接口 A：场内 ETF 行情（`clist`）

```
https://push2.eastmoney.com/api/qt/clist/get
  ?pn=1&pz=100&po=1&np=1&fltt=2&invt=2
  &fid=f20                     # 排序字段（f3 涨跌幅 / f20 规模 …）
  &fs=b:MK0021,b:MK0022,b:MK0023,b:MK0024,b:MK0827   # 板块过滤
  &fields=f2,f3,f4,f5,f6,f7,f8,f10,f12,f13,f14,f15,f16,f17,f18,f20,f21,f22,f26,f62,f124,f402
```

### 1.1 板块取值（`fs`）实测

| `fs` | 含义（实测样本推得） | 条数 |
|---|---|---|
| `b:MK0021` | 股票型 ETF（沪深） | 1338 |
| `b:MK0022` | 货币 ETF | 27 |
| `b:MK0023` | 跨境 ETF（QDII） | 241 |
| `b:MK0024` | 商品 ETF（黄金 10 只） | 10 |
| `b:MK0827` | 商品 ETF 全集（黄金 14 + 豆粕/有色/能源化工 3） | 17 |
| 上表五者并集 | **全市场 ETF** | **1623** |
| `b:MK0025`/`MK0026`/`MK0027`/`MK0028`/`MK0404` | LOF / 分级，**不是 ETF** | — |

- 实测 `MK0024 ⊂ MK0827`（10 只黄金 ETF 同时命中两者），
  所以取并集后是 1623 而不是 1633 —— 采集端必须按代码去重。
- `m:1+b:MK0021` = 745（沪市）、`m:0+…` 可分离深市；但**不必**拆板块请求，
  行内 `f13` 已经给了市场（1 = 沪市，0 = 深市）。

### 1.2 字段语义（含实测样例）

500 行样本 `< 12 行裁剪版` 见 `packages/sources/test/fixtures/eastmoney/etf-spot/boards.json`。

| 字段 | 含义 | 单位/样例 |
|---|---|---|
| `f12` | 代码 | `510300` |
| `f14` | 简称 | `沪深300ETF华泰柏瑞` |
| `f13` | 市场 | `1` 沪 / `0` 深 |
| `f2` `f18` `f15` `f16` `f17` | 最新价 / 昨收 / 最高 / 最低 / 今开 | 元 |
| `f3` `f4` | 涨跌幅 % / 涨跌额 | `3.55` / `0.05` |
| `f5` `f6` | 成交量（手）/ 成交额（元） | `114941` / `16845295` |
| `f7` `f8` `f10` `f22` | 振幅 % / 换手率 % / 量比 / 涨速 % | |
| `f20` `f21` | 总市值 / 流通市值（≈ **场内规模**，元） | 510300：`109391241858`（1093.9 亿） |
| `f26` | **上市日期** | `20120528` |
| `f62` | 主力净流入（元） | |
| `f124` | 行情时间戳（秒） | `1790064693` → 2026-09-22 16:11 |
| `f402` | **`−溢价率`（%）** | `0.06` = 折价 0.06% |

> **`f402` 的符号约定与 `packages/sources/src/eastmoney/quote.ts` 完全一致**：
> `f402 = (净值 − 价格) / 净值 × 100`，负值代表**溢价**。
> 实测 510300：`f2 = 4.613`、`f402 = 0.06` → 净值 ≈ 4.6158，折价 0.06%。
> 归一化到对外字段时取反（`premiumRate = −f402`），让「正 = 溢价」与中文语义一致。

> **`fltt=2` 必须带**：不带时数值按 ×100 / ×1000 缩放
> （同一个 510300：`f2=4613`、`f402=6`），会在前端渲染出 1000 倍的价格。

### 1.3 分页：`pz` 上限实测 100

| `pz` | 实际返回行数 |
|---|---|
| 100 / 200 / 500 / 1000 / 2000 | **100**（全部被截断到 100） |

因此全市场 1623 只必须翻 **17 页**（`pn=1..17`，`pz=100`）。
翻页终止条件用「本页返回行数 < 100」或「已收集 ≥ `data.total`」，
并对 `data.total` 做上限护栏（> 5000 直接 `ParseError`，避免上游异常导致无限翻页）。

### 1.4 主备域名与限流（**重要**）

| 域名 | 实测 |
|---|---|
| `push2.eastmoney.com` | 正常可用；短时间内高频访问后会被**静默重置 TLS**（`SSL_read: unexpected eof`），curl 与 Node 均命中 |
| `push2delay.eastmoney.com` | 延时行情，备用域名，`fs=b:MK0021` 只回 1338（少了跨境/商品板块） → **只能当兜底**，不能当主源 |

实测经验：同一 IP 连续 30+ 次请求后主域名开始拒绝连接，冷却数分钟后恢复；
`quote.ts` 早已采用「主域名 → 备用域名」的自动切换，本工具复用同一策略。

## 2. 接口 B：ETF 目录（跟踪指数 + 分类）

```
https://datacenter-web.eastmoney.com/api/data/v1/get
  ?reportName=RPT_FUND_ETFLIST&columns=ALL&pageSize=1000&pageNumber=1
  &sortColumns=SECURITY_CODE&sortTypes=1
```

- 实测 `count = 1675`、`pageSize` 上限 1000 → **2 页**取全（`pages = 2`）。
- 返回 1675 行 ⊇ 接口 A 的 1623 只：多出来的是**已成立未上市**（无场内行情）的新 ETF，
  例如 `158000 港股通金融ETF鹏华`。工具以「有行情」为准，未上市的在统计里单列。

| 字段 | 含义 |
|---|---|
| `SECURITY_CODE` / `SECURITY_NAME_ABBR` / `SECUCODE` | 代码 / 简称 / `510300.SH` |
| `INDEX_CODE` / `INDEX_NAME` | **跟踪指数**代码（`000300`、`H11146`）与名称（`沪深300`）|
| `DERIVE_INDEX_CODE` / `TRACKINDEX_QUOTES_CODE` | 指数行情代码（`000300.SH` / `000300.2`）|
| `DEC_NAV` / `DEC_TOTALSHARE` | **规模（亿元）/ 份额（份）** —— 见下方交叉验证 |
| `CHANGE_RATE_1W` / `_1M` / `_3M` / `YTD_CHANGE_RATE` | 近 1 周 / 1 月 / 3 月 / 年初至今涨跌（%）|
| `MAXDRAWDOWN1Y` | 近 1 年最大回撤（%，负值）|
| `IS_*ETF` | 分类标志位，见 2.2 |

### 2.1 `DEC_NAV` 是「规模（亿元）」而不是「净值」—— 三处交叉验证

| 代码 | `DEC_NAV` | `DEC_TOTALSHARE` | 相除得单价 | 与行情对照 |
|---|---|---|---|---|
| `510300` | 1093.699 | 23,713,687,700 | 4.613 元 | 与 `f2 = 4.613` 一致 |
| `513100` | 189.558 | 9,552,110,600 | 1.985 元 | 与基金净值 1.9831 一致 |
| `511990` | 967.251 | 967,251,000 | **100** 元 | 货币 ETF 场内面值 100 元 |
| `159985` | 35.251 | 1,579,924,066 | 2.231 元 | 与豆粕 ETF 价格一致 |

且 `510300` 的 `DEC_NAV ≈ f20 / 1e8`（1093.7 亿 vs 1093.9 亿）。
**结论**：`DEC_NAV` 单位是亿元、含义是「价格 × 份额」的规模估算；
本工具以接口 A 的 `f20` 为主、`DEC_NAV` 作为缺失时的回退。

### 2.2 `IS_*ETF` 标志位语义（逐个人工核对样本）

| 标志位 | 含义 | 为 1 的行数 | 抽样证据 |
|---|---|---|---|
| `IS_HBETF` | 货币 | 27 | `159001 货币ETF易方达`、`511990 华宝添益ETF`（与 `MK0022` 的 27 完全吻合）|
| `IS_WPETF` | 跨境 | 246 | `513100 纳指ETF国泰`、`159010 港股通科技ETF博时` |
| `IS_ZQETF` | 债券 | 53 | `159110 科创债ETF万家`、`159111 科创债ETF天弘` |
| `IS_SPETF` | 商品 | 17 | `159985 豆粕ETF华夏`、`518880 黄金ETF华安`（与 `MK0827` 的 17 完全吻合）|
| `IS_KJETF` | **宽基** | 373 | `510300 沪深300...`、`159337 中证500ETF东财`、`159215 A500ETF平安`、`159247 创业板ETF汇添富` |
| `IS_HYETF` | **行业主题**（HangYe） | 812 | `512880 证券ETF国泰`、`158010 医疗ETF嘉实` |
| `IS_FGETF` | **风格**（FengGe） | 189 | `158023 红利低波ETF万家`、`159021 大盘价值ETF华夏` |
| `IS_HSETF` / `IS_HSMARKET` | 沪深（境内）市场 | 1332 / 1492 | 跨境行为 0 |

- **`IS_HBETF`…`IS_HYETF` 六者互斥**（实测无一行同时命中两个），构成一个完整划分：
  `27 + 246 + 53 + 17 + 373 + 812 = 1528`，其余 147 行只命中 `IS_FGETF`（风格）。
- `IS_FGETF` 是**叠加维度**：有 42 行同时命中「宽基/行业主题」。工具里把它排在
  宽基/行业主题**之前**（先风格后宽基），具体优先级见设计文档 §3.1。
- 推断依据是「标志位缩写 = 中文分类拼音首字母」+ 样本核对；**没有官方文档**，
  因此解析层保留原始四个分类字段的布尔值，分类优先级放在 `core`（可测、可改）。

| `NETNAV` | 场内/份额规模（元） | `33194696674.25` |
| `ESTABDATE` | 成立日期 | `2012-05-04` |

## 5. 请求预算（克制原则）

- **每次快照 19 个请求**（A 17 页 + B 2 页），约 2 MB；
- 定时任务只在**交易时段**跑：`*/30 9-15 * * 1-5` → 每天 14 次 ≈ **266 请求/天**；
  收盘后不再重复打上游（最后一次 15:30 已包含当日收盘价）。
- 接口 C 只在用户点开详情抽屉时调用，并按 `code` 落库缓存。

## 6. 实测发现与风险（2026-09-22）

| 项 | 实测 | 结论 |
|---|---|---|
| 全市场 ETF（接口 A 并集） | **1623 只** | 与 `MK0021+MK0022+MK0023+MK0024` 的 1616 相比，补上 `MK0827` 的 7 只非黄金商品 ETF |
| ETF 目录（接口 B） | **1675 行** | 多出的 ~52 只是已成立未上市的新基金 |
| 规模合计 | 股票/跨境/货币/商品合计 **约 5.9 万亿元** | 单只最大 510300（1094 亿）|
| 折溢价 | 绝大多数 |`f402| ≤ 0.5%`，跨境 ETF 盘中溢价常见、最高见 1%+ | 「转战场内」的代价可量化 |
| 单只样例 | `589410 科创人工智能ETF嘉实` `f26=20260716`（2026-07-16 上市）| 上市日期字段对新 ETF 有效 |
| 限流 | 主域名高频请求后 TLS 被重置（curl/Node 均命中），冷却后恢复 | 必须保留备用域名 + 长缓存 + 只在交易时段跑 |
| `push2delay.eastmoney.com` | 只覆盖 `MK0021` 的 1338 只 | 兜底可以，但要接受「跨境/商品板块缺失」的降级 |

**尚未验证**：`f402` 在非交易时段是否等于「上一交易日收盘价 vs 最新净值」（实测收盘后为 0.0x 量级，
符合静态口径，但未做跨日对比）；接口 B 的 `CHANGE_RATE_3M` 对次新 ETF 为 `null`（已按可空处理）。
